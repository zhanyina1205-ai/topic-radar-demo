# 选题雷达 · 公开试用版

[打开试用页](https://zhanyina1205-ai.github.io/topic-radar-demo/)

直接选择赛道和时间范围，点击选题标题查看创作提纲和话题出处。星标仅存储在当前浏览器。页面在打开时读取微博、抖音的公开日归档，离线源使用注明日期的历史快照。归档许可证位于 notices。

[完整工作台](https://yenai-topic-radar.zhanyina1205.chatgpt.site/) 供已获访问权限的账号使用。

「博主作品」使用 B 站综合热门和分区排行中的公开投稿。GitHub Actions 每 4 小时尝试更新一次作者、原作、发布时间及互动数据，某个来源暂不可用时保留最近一次有效观测。只比较所选日期内发布、同平台、同形式和同赛道的样本。每组至少 4 条，取按累计点赞排名前四分之一（名额向上取整）且高于中位数的作品。卡片显示样本量、名次、中位数和采集时间。
